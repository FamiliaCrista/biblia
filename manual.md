## Visão Geral

A **Bíblia Sagrada Online** é uma plataforma web completa para leitura, estudo e projeção da Bíblia Sagrada. O aplicativo foi desenvolvido 100% em HTML, CSS e JavaScript puro (sem frameworks), com foco em performance, usabilidade e recursos para estudo bíblico e ministério.

### Principais recursos

- 9 versões da Bíblia (incluindo texto original em Hebraico e Grego)
- Modo Leitura contínua
- Sistema de projeção (Slide) para Datashow/TV
- Concordância Bíblica com números de Strong
- Dicionário Bíblico
- Harpa Cristã (640 hinos) e Cantor Cristão (581 hinos)
- Projeção de hinos
- Biblioteca de Bíblias de estudo em PDF
- Portal de cursos gratuitos

## 1. Página Inicial — Escolhendo a Versão

Ao abrir o aplicativo, você verá a tela **“Versões da Bíblia”**.

Cada card representa uma tradução disponível:

| Código | Nome da Versão                          |
|--------|-----------------------------------------|
| ACF    | Almeida Corrigida Fiel                  |
| ARA    | Almeida Revista e Atualizada            |
| ARC    | Almeida Revista e Corrigida             |
| KJV    | King James Version                      |
| NAA    | Nova Almeida Atualizada                 |
| NTLH   | Nova Tradução na Linguagem de Hoje      |
| NVI    | Nova Versão Internacional               |
| NVT    | Nova Versão Transformadora              |
| ORIGINAL | Texto Interlinear Hebraico e Grego    |

**Como usar:** Clique em qualquer card para entrar no leitor daquela versão.

---

## 2. Leitor Bíblico (Tela Principal)

A tela do leitor é organizada em três níveis de navegação:

### Menu Lateral (Livros)
Lista os 66 livros da Bíblia. Clique no nome do livro desejado.

### Régua de Capítulos
Após selecionar o livro, aparece a numeração dos capítulos. Clique no número do capítulo.

### Grade de Versículos
Após escolher o capítulo, aparece a grade com os números dos versículos. Clique em um número para ler o texto.

### Navegação entre capítulos
Use os botões **Cap. Anterior** e **Cap. Próximo** para avançar ou voltar.

---

## 3. Modo Leitura

Ideal para leitura devocional contínua e sem distrações.

1. Selecione um livro e um capítulo.
2. Clique no botão **Modo Leitura** no menu superior.
3. O capítulo inteiro será exibido de forma contínua.
4. Use os botões **Capítulo Anterior** e **Capítulo Próximo** na parte inferior para navegar.

Para sair do Modo Leitura, clique novamente em **Modo Leitura** ou escolha outro livro/capítulo.

---

## 4. Modo Slide (Projeção para Datashow / TV)

Recurso projetado para cultos, estudos e reuniões.

1. Selecione o livro, capítulo e versículo desejado.
2. Clique no botão **Slide** no menu superior.
3. Uma nova janela será aberta, otimizada para projeção.
4. Navegue pelos versículos usando os botões ou o teclado.

### Atalhos de teclado no Slide Bíblico

| Tecla              | Ação                          |
|--------------------|-------------------------------|
| → ou Page Down     | Próximo versículo             |
| ← ou Page Up       | Versículo anterior            |
| Home               | Vai para o versículo 1        |
| End                | Vai para o último versículo   |

---

## 5. Concordância Bíblica

Ferramenta para localizar todas as ocorrências de uma palavra na Bíblia.

1. No menu superior, clique em **Concordância e Dicionário**.
2. Na aba **Concordância**:
   - Use a barra lateral (A–Z) para filtrar por letra.
   - Ou digite a palavra no campo de busca e clique em **CONSULTAR**.
3. Cada resultado mostra:
   - Quantidade de ocorrências
   - Referências bíblicas onde a palavra aparece
   - Número de Strong (quando disponível)

---

## 6. Dicionário Bíblico

Explica o significado de termos, pessoas, lugares e doutrinas bíblicas.

1. Na mesma tela da Concordância, clique na aba **Dicionário**.
2. Navegue pelas letras (A–Z) ou digite o termo no campo de busca.
3. Ao clicar em um termo, você verá:
   - Definição principal
   - Definição espiritual / cristocêntrica
   - Referências bíblicas relacionadas

---

## 7. Harpa Cristã e Cantor Cristão

Biblioteca digital completa dos dois principais hinários evangélicos do Brasil.

1. No menu superior, clique em **Harpa e Cantor**.
2. Escolha entre:
   - **Harpa Cristã** (640 hinos)
   - **Cantor Cristão** (581 hinos)
3. Selecione a faixa de hinos (ex: 1–50, 51–100...).
4. Clique no hino desejado para ver a letra completa.

### Slide de Hinos

1. Com o hino aberto, clique em **Slide**.
2. Uma janela de projeção será aberta com as estrofes.
3. Navegue com as setas do teclado ou botões **Anterior / Próximo**.

### Atalhos de teclado no Slide de Hinos

| Tecla                    | Ação                    |
|--------------------------|-------------------------|
| → , Page Down ou Espaço  | Próxima estrofe         |
| ← ou Page Up             | Estrofe anterior        |

## 10. Texto Original (Hebraico e Grego)

Recurso avançado para estudo interlinear.

1. Na página inicial, clique no card **Bíblia Sagrada – Hebraico e Grego**.
2. Navegue normalmente por livros e capítulos.
3. No **Modo Leitura**, o texto aparece interlinear com:
   - Palavra original (Hebraico ou Grego)
   - Transliteração (pronúncia)
   - Tradução palavra por palavra
   - Tradução completa do versículo

O Antigo Testamento é exibido da direita para a esquerda (RTL). O Novo Testamento segue o fluxo normal (LTR).

---

## 11. Busca Rápida

Em várias telas há um campo de busca no canto superior direito.

1. Digite a palavra ou trecho desejado.
2. Clique em **Buscar**.
3. Os resultados mostram as referências encontradas.
4. Clique em qualquer resultado para ir diretamente ao versículo.

---

## 12. Sobre o Projeto

1. Clique em **Sobre** no menu superior.
2. Será exibida uma janela com informações sobre o projeto, versões disponíveis e funcionalidades.

## Dicas de Uso

- A versão da Bíblia escolhida é lembrada automaticamente pelo navegador.
- O aplicativo funciona melhor quando aberto por um servidor local (Live Server no VS Code ou `python -m http.server`).
- Use o **Modo Slide** em uma segunda tela ou projetor para apresentações.
- A Concordância e o Dicionário são excelentes para estudos temáticos e preparo de mensagens.
- Os hinários possuem projeção própria, ideal para o ministério de louvor.

---

## Como Executar Localmente

### Opção recomendada: Live Server (VS Code)
1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html` → **Open with Live Server**.

### Opção alternativa: Python
```bash
python -m http.server 8000
```
Depois acesse: `http://localhost:8000`
